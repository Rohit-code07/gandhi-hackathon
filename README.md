# 🖥️ Windows 98 – The Nostalgic Desktop Experience

> Bringing back the golden era of personal computing with a modern, interactive Windows 98-inspired web experience.

A creative web-based recreation of the classic Microsoft Windows 98 interface, designed to bring nostalgia to modern browsers. This project recreates the iconic look and feel of Windows 98 while introducing interactive elements and unexpected surprises.

## 🚀 Project Overview

Remember the classic teal desktop, the iconic Start button, and the legendary Windows 98 interface?

This project recreates that nostalgic experience through a browser-based interface, combining retro aesthetics with modern web development.

But there's a twist!

We've introduced **"The Great Start Button Chase"** — a fun Easter egg where the classic Start button becomes an unexpected challenge.

The goal is simple: try to catch the Start button!

## ✨ Key Features

### 🪟 1. Windows 98-Inspired Interface

* Classic Windows 98 visual design.
* Iconic teal desktop background (`#008080`).
* Retro-inspired UI elements.
* Authentic Windows 98 branding aesthetics.
* Nostalgic startup and welcome experience.

### 🎮 2. The Great Start Button Chase

An interactive Easter egg that adds a humorous twist to the traditional Windows experience.

* A classic Windows 98-style Start button.
* Unexpected interactive behavior.
* A playful challenge for users.
* Designed to surprise users with an unconventional interaction.

### 🎨 3. Retro UI Experience

* Classic desktop-inspired styling.
* Nostalgic Windows-era visual elements.
* Pixel-inspired design details.
* A combination of simplicity and playful interactions.

## ⚙️ Getting Started

Follow these instructions to run the project locally.

### Prerequisites

* Node.js
* npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/Rohit-code07/gandhi-hackathon.git
```

### 2. Navigate to the Project

```bash
cd gandhi-hackathon
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit the local URL displayed in your terminal.
